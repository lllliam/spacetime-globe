# 书卷范例与维护指南

1.0《明朝》标杆书卷按五部安排相互衔接的主线章与专题章。漕运专题围绕一笔税粮经历的交兑和换运展开，地球说明淮安处于江南粮区与北方京师之间的地理位置，脚注把具体年代与运输制度分别定位。其他书卷可照自身的史料与叙事需要选择结构。[标杆报告](progress/PHASE-08.md) · [产品规范](PRODUCT-SPEC.md) · [历史内容模型](HISTORY-MODEL.md) · [原型写作模板档案](archive/design/BOOK-EXEMPLAR-GUIDE-PROTOTYPE.md)

- **卷和章。** 围绕读者需要理解的历史问题选材，交代时序、行动者、抉择、后果和延续。章节及长度服从史料与叙事需要，保留可追溯的书卷和章节身份。
- **正文与引用。** 空间论点、具体史事、微观材料与延伸内容各自提供可辨认的信息。关键论断能在段落引用中查证，区分原始文献、研究者解释与编辑推断。材料存疑时保留明确的审校状态。
- **场景。** 每幅图版从正文提出一个空间问题。将时间、地点和路线的精度绑定到实际证据；资料只支持位置的场景可以专注于比较或定位。章后关系须说清是并读同一时期、比较一个问题，还是有资料支持的接触。[历史现场规范](HISTORICAL-SCENES.md) · [阅读与内容组织](READING.md)
- **现有数据规则。** 目录可有一章或多章，章节可并行、留空档或跨年代回顾，正文长度由论述需要确定。地图绑定按书卷的内容范围选填。校验检查身份、年代、来源与关系，存量史料逐条审校归 Phase 07。[历史内容模型](HISTORY-MODEL.md)

最终内容验收见 [验收标准](ACCEPTANCE.md)。

Phase 08 标杆书卷以 [历史编辑规范](EDITORIAL-STANDARD.md) 延续 Phase 07 的审校方式。正文、空间解释、引语和延伸阅读各自回到实际材料。读者能在同一处区分可确认的事实、解释分歧及证据不足，并可从正文追到材料的具体位置。[存量审校实例](progress/PHASE-07.md)

- 保留旧章和段落身份。改写曾以内容指纹保存位置的段落、附注时，可将真实旧构建产生的单个指纹记在 `previousFingerprint`。恢复时会在当前正文找匹配，然后升为稳定块 ID。验证时由旧构建实际写入会话。[标杆兼容检查](progress/PHASE-08.md#阅读和兼容性)
- 给早期、盛期或晚期地图入口配置能体现该时间问题的推荐。对已有明确历史对象的定向入口，检查是否已有更精确的章节。年代相重叠的章节仍按编辑顺序展示。[《明朝》入口与目录](progress/PHASE-08.md)
