# 书卷范例与维护指南

**部分有效。** 原型《明朝》展示了正文、引文和空间解释的结合。1.0《明朝》标杆书卷由 Phase 08 按对应产品指令完成。[原型写作模板](archive/design/BOOK-EXEMPLAR-GUIDE-PROTOTYPE.md)保留了当时对卷型、章数、段数和篇幅的要求。后续以 [产品规范](PRODUCT-SPEC.md) 确定内容边界与叙事篇幅。

- **卷和章。** 围绕读者需要理解的历史问题选材，交代时序、行动者、抉择、后果和延续。章节及长度服从史料与叙事需要，保留可追溯的书卷和章节身份。
- **正文与引用。** 空间论点、具体史事、微观材料与延伸内容各自提供可辨认的信息。关键论断能在段落引用中查证，区分原始文献、研究者解释与编辑推断。材料存疑时保留明确的审校状态。
- **场景。** 在段落附近提供读者可主动进入的图版。场景说明一个可观察的空间关系，按证据解释时间、地点、角色、路线及其不确定性。当前字段见 [阅读与内容组织](READING.md)。
- **现有数据约束。** `tools/subject-books.mjs` 目前要求每卷至少两章、章内至少三段、年代连续且至少绑定一个底图政权，并检查段落来源索引。补充专题另有结构和长度校验。跨这些约束的变化归 Phase 05，存量审校归 Phase 07。

最终内容验收见 [验收标准](ACCEPTANCE.md)。
