# 历史编辑规范

时空地球的书卷从人、制度和空间出发解释历史变化。普通书卷可以是简明概述，扉页写清叙事范围和资料截止年。以人物处境、可追踪的决定、制度的落实和普通人的生活组织段落。让地图回答正文提出的空间问题。[产品规范](PRODUCT-SPEC.md)

## 论断与材料

| 论断 | 核查办法 |
| --- | --- |
| 人物、事件和年代 | 核对历史名称、对象身份、活动范围和纪年口径。学界分期或换算不同时写近似时间或说明差异。 |
| 引语与史料转述 | 核对可访问的文献原文、版本、页码或条款。保留作者身份和成文语境。译述须忠实于原意。无法定位的直接引语改为有依据的转述或撤下。 |
| 数字与比较 | 核对资料年份、覆盖地理范围、指标、单位、估算方法与不确定性。同一报告的转引沿用同一证据链。现代统计注明数据年份和指标口径。 |
| 制度与政策 | 区分法令、官方自述、执行和群体所受影响。制度名称和解释随实际历史语境。 |
| 历史解释 | 写明长期背景、直接诱因及不同因素的作用。涉及人物动机或制度因果时，定位相关材料和研究依据。 |
| 争议与不确定性 | 说明主要分歧、证据能支持的最小范围及原因。数字无法可靠估算时可说明伤害和不确定性。 |

优先查可定位的原始文献、考古报告、档案与可读的研究。大学、博物馆、研究机构及有专业编辑的参考资料，可用于其确实覆盖的事实。记录官方文件的发布主体和用途，也核对独立研究。单一原始材料可能有立场及记录局限。多项材料出自同一研究时，视为同一证据链。摘要只能支持其明确说出的内容。访问结果与论断支持分别记录。[来源核查](SOURCE-AUDIT.md)

各地区、族群和政治制度采用一致的证据标准。战争、奴役、饥荒、强迫迁徙和政治迫害写明行动者、受影响群体及制度背景。涉及死亡估计时，写明估算范围和来源，保留研究之间的差异。保留地方社会和普通人如何应对变化的材料。用具体行动、利益和后果推动叙事，缩减戏剧化修辞与空泛形容。

地理区域、历史政权、文明与现代国家各有各自的范围。底图代表特定资料覆盖，地图关系需要可解释的入口语义。现代区位参照要有清晰提示。共时只陈列可比年份，比较须说明维度，实际联系需要支持联系本身的史料。场景按证据表达地点、日期、线路及方向；直线距离只描述地理尺度。[历史内容模型](HISTORY-MODEL.md) · [历史现场](HISTORICAL-SCENES.md)

## 执行和记账

1. 锁定书卷、章节、正文块或辅助文本 ID。读完本批实际正文、摘要、说明及已有证据，拆出影响理解的事实、数字、解释与争议。先处置错误身份、严重伤害叙事和其他高风险问题。
2. 打开资料的相关部分，记录实际访问状态、日期、题名、作者或机构及具体出处。只访问到摘要、被限流、受权限限制或暂时失败，都用各自状态记录。对期刊和书目，注明实际读到的部分。
3. 在审校记录写明每项材料确切支持的论断及边界，再保留、改写、限定、暂停或登记待查。`checked` 必须有这些证据、具体范围和实际日期。`issues`、`insufficient`、`disputed` 写清问题或分歧。`legacy` 继承历史记录，`unreviewed` 留给仍待审阅的对象。正文附近展示会影响判断的重要材料限制。
4. 同一内容身份保留原稳定 ID。拆分时原 ID 留给承接原论点的块，补充资料使用新 ID。链接切换只有在确属同一资料的新地址时才沿用来源身份，并在差异中记录。每次变更复核正文引用、场景、地名链接及关联入口。
5. 保存逐项审查、来源访问和变更记录，运行结构、引用、稳定身份及线上、离线可用性检查。保留风险筛查和未查队列。审查覆盖率以实际读查并处置的对象为分子，证据核实率以实际得到适当材料支持的论断为分子。
6. 第二遍复核重新打开材料。逐项复查一级风险、新增的争议数字和引语、改动主叙事关系的绑定、重启的场景与新确认的历史联系。每卷取一个代表块，按地区和题材做分层抽查，记录实际样本、复核人和结论。由同一编辑完成时说明复核性质。

发布前检查叙事边界、重点事实、证据定位、争议呈现、入口、旧进度与离线读取。史料审查结果和结构通过各自记录。正在编辑的批次有独立进度记录。[Phase 07](progress/PHASE-07.md)

Phase 07 暂存期间，经授权维护既有历史内容时，沿用上述编辑和证据要求，并登记受影响论断的现行审校范围。[暂存期间的内容变更](SOURCE-AUDIT.md#暂存期间的内容变更)
