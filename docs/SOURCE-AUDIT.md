## 编辑检查的重点

- 区分现代国家入口与历史疆域，区分事件定位点与完整发生范围。
- 核对主要年代、名称与事件顺序；南亚补入德里和汉皮，防止把1200—1526年的跨度空列在莫卧儿之前。
- 将汉、罗马等跨时期比较标为对照，不暗示直接因果关系；同期世界与相关背景分别标明。
- 清除晚清概览残留的“六个节点”，与新增八篇一致。
- 将玛雅城邦衰落、普韦布洛迁徙、非洲城市变化与人群延续区分；不把遗址停用写成人口消失。
- 对殖民、奴役、种族灭绝与强制同化明确行动者和制度，不用交流或发展成果抵消伤害。
- 当代世界的观察终点为2024年，未将其描述为2026年的实时局势。

### 暂存期间的内容变更

在 Phase 08 或其他获准的工作中改动历史内容时，在实施批次或阶段报告中记录稳定 ID、变更前后及对应提交、受影响的论断和资料定位、现行审校状态或待复核范围。旧批次的原文与证据保持可按 Git 提交追溯。改动后的正文只有在新版本的论断与证据明确匹配并经实质复核后，才能按已核实计入现行结果。正文旁展示的审校状态或范围随实际证据调整。

同一存量稳定 ID 在现行覆盖率只计一次。补充对象可独立登记，对照原存量清单核算分子和分母。确需拆分时，保留原 ID 给承接原论点的内容，新对象使用新 ID，并记录它与原对象的对应关系。续审合账时按 ID 更新现行处置，不追加同 ID 的重复记录。旧记录使用对应提交回看。

审校专项能比对存量身份、来源和台账产物。它接受符合格式的既有审校记录，事实状态仍需根据正文差异和审校范围逐项核对。先记录所受影响的范围和重新查证结果，再重算当前清单。暂存检查点、一级待审项的筛选方法及基线复现命令见 [Phase 07 暂存与恢复](progress/PHASE-07.md#暂存与恢复)。

## Phase 08 标杆台账

将 `git archive 5bae983 data` 和 `git archive 2d8233b data` 解入不同的临时目录。先传 Phase 06 归档根，再通过 `--phase-08` 传 Phase 07 内容检查点归档根。

```sh
node tools/verify-editorial-audit.mjs <5bae983 解档根目录> --phase-08 <2d8233b 解档根目录>
```

同一命令加 `--write` 可重建 Phase 08 的变更对照和统计。Phase 07 原台账在此模式下按 `2d8233b` 只读复现，覆盖仍为 387／5,576、一级未审候选仍为 106。标杆批次记录实际访问、定位、能支撑的论断、限制和复核范围。工具检查当前稿保存旧稳定 ID、每个新来源具备访问记录、修订或新增对象有对应处置、证据定位可在访问记录中匹配。[批次记录](progress/phase-08/batches/) · [前后变更](progress/phase-08/changes.json) · [统计](progress/phase-08/summary.json)

续审时先按稳定 ID 对照两个台账。Phase 08 修订版本的审校结果仅覆盖当批已检查的论断。核实同一旧对象时记入原存量身份一次，新增对象续列其独立范围，受影响的其余论断继续待核查。[Phase 07 暂存与恢复](progress/PHASE-07.md#暂存与恢复)
