# 核心状态与导航

核心状态由 Phase 02 建立，Phase 03 接入探索，Phase 04 接入全屏阅读，Phase 05 接入稳定正文块锚点。产品决策见 [产品规范](PRODUCT-SPEC.md)，原型审查见 [工程基线](BASELINE.md)。

## 状态所有权

| 状态或对象 | 所有者与职责 |
| --- | --- |
| `session.mode` | `session-state.js` 管理唯一核心模式 `Explore`、`Read`、`Observe`。`reading.active` 是对模式的只读投影 |
| `session.explore` | 探索控制器在选年、切换显示方式、完成镜头操作或进入其他模式时提交。包含年份、有效图层、跟随时间和显示偏好、镜头、选择和摘要返回位置 |
| `session.read` | 阅读控制器通过 `beginReading`、`openReadingDetail`、`navigateReading` 和 `readingGoBack` 更新。包含书卷／专题 ID、地图档案标识、章节 ID、入口年、阅读层级、正文锚点、目录位置、来源和导航栈。书卷和专题由 ID 动态查找 |
| `session.observe` | `event-map.js` 启动和更新独立观察。包含场景／世界事件 ID、阶段、观察年、地点、最近镜头和返回目标。观察从阅读进入时只隐藏纸面，保留完整阅读上下文 |
| `state`、`view` | 地球渲染器拥有实时绘制年、视角、缩放、平移、坐标投影和分区拾取。镜头动画逐帧运行，业务快照在用户操作和导航节点更新 |
| `sheetState`、`chrome.panel`、选年面板、时间游标预览、史事列表、脚注 | 各模块管理的临时界面。摘要档位和列表恢复信息随相关来源记录 |
| `worldEvent` | 观察图层的标记和参与方视图。独立观察阶段及地点从协调层读取，探索业务快照由自身维护 |
| `globe.reading-display.v1` | 四档字号偏好，独立于 Explore、Read 及 Observe 会话的导航状态 |
| 拖动、动画与焦点 | 指针、动画帧、临时 DOM 焦点只属于当前页面。位置换算和已完成的导航由业务状态记录 |

原型曾在 `reading.snapshot`、`reading.returnTo` 和世界事件视图各自记录去向，在正文进入场景时销毁阅读后靠回调恢复。现由协调层保存来源，`reading.trail` 保存可序列化的 ID 和位置，读书进度由一个集合按书卷或专题分开存储。世界列表使用年份、事件 ID、操作类型、折叠项和滚动位置作为返回描述。

## 导航与三种年份

| 转换 | 稳定规则 |
| --- | --- |
| Explore → Read | 保存探索并记录摘要、地图或事件列表来源。入口年来自实际入口，章节年代来自内容 |
| Read → Observe → Read | 保留完整阅读会话，投影独立场景的年份和镜头。切换场景、阶段或地点持续使用同一返回目标。退出时恢复正文锚点、必要焦点和进入观察前的阅读地球 |
| Read → Explore | 保存进度，重新投影探索年份、图层、偏好和镜头。按已验证的身份重建摘要，或恢复事件列表位置与焦点 |
| Explore → Observe → Explore | 观察使用事件年份和地理数据，返回原探索及对应事件列表 |
| 事件 Observe → Read → Observe | 兼容事件地图的「阅读正文」。当前会话收起书卷时恢复同一事件、地点和镜头。重载时恢复有效阅读，之后可回到探索的事件列表 |

例如 1500 年探索进入《明朝》，书卷入口年仍为 1500，阅读章可涵盖 1399—1435 年。漕运观察由 1411 年进入，切换阶段可用 1415 或 1421 年。合书后恢复 1500 年探索。打开书卷、目录或字号设置时地球暂停绘制。

`navigateBack` 处理 Escape，依次关闭注释或临时面板、退出观察、回到上一阅读节点、退出阅读、收起探索列表或摘要。现有手势和可见返回按钮调用对应返回入口。进入新状态时取消旧镜头、抽屉、指针和滚动回调。重复退出会由模式守卫拒绝，同一路由的重复链接不进入栈。

## 本地保存和启动恢复

- 本地键为 `globe.session.v1`，独立 `schemaVersion: 1`。数据包含稳定模式、`explore`、最近阅读记录 `read` 和分卷／专题进度 `progress`。导航栈最多 24 条，进度最多 120 项。书卷正文、地图、DOM 与正在运行的动画都在运行时加载。
- 探索选择使用现代 ISO 或历史实体 ID 与底图原名，并保存有用的地图坐标。读写镜头数值时验证有限值和合法范围。跨尺寸重开时按地球半径比例投影平移，渲染器约束可见范围。
- 正文锚点包含卷／专题、章、可选 `blockId`、正文块顺序、文本指纹、块内比例和 `scrollTop`。已有 `blockId` 的记录在块改写或重排后仍定位到同一块，块删除时回退同章的 `scrollTop`。旧记录用原块顺序与文本指纹定位，命中后把 `blockId` 写入当前记录及与之对应的分卷／专题进度。已展开的章后说明及来源随正文快照保存。目录使用各自滚动位置，章节目录返回按导航栈恢复。
- 导航提交、选年、相机与抽屉落位、节流后的滚动，以及 `visibilitychange` 和 `pagehide` 保存。渲染帧、指针移动和原始滚动事件在内存处理。写入前核对当前存储是否仍和本页上次读取或写入的快照一致。读者主动操作旧页面时，先读取共享记录中最新的分卷进度，再保存本页的实际变化。
- 启动先建立世界索引、分区与画布，然后读取并投影会话，恢复完成前跳过写入。无有效记录时从 1500 年与亚洲镜头起步，等候该年疆域数据。有效恢复保留原年份、镜头和显示偏好。历史疆域加载后再次验证年份、图层、身份和本次恢复序号。用户的新输入取消待恢复的选择。
- 有效 Read 记录恢复目标与锚点，缺章退回目录，缺卷或档案实体退回探索。Read 进入的 Observe 在重启时恢复 Read，Explore 进入的 Observe 恢复原 Explore，来自史事列表时恢复记录的年份、折叠、滚动与入口焦点。临时弹窗不会重开。损坏 JSON、未知 schema、隐私限制、权限或配额异常走安全降级。旧 `globe.display.v4` 仍用于兼容读写。
- 旧记录中的 `viewMode` 字段由读取器忽略，书卷、章节、来源、导航链、进度和探索记录按 schema 1 读写。事件观察进入阅读后可临时悬挂该观察，供主动进入正文场景并返回后继续使用。
- 在线和单文件共用逻辑。浏览器允许本地文件存储时可恢复相同文件地址的会话。浏览器限制本地文件存储时，阅读与探索仍可在当前页面正常使用。
- 进度与显示偏好留在同浏览器和相同来源，主屏幕的存储隔离以实际系统行为为准。PWA 更新管理资源缓存，应用读写既有的 `globe.session.v1` 和偏好键。浏览器系统返回沿原网页导航，页面内的分层返回使用应用按钮和 Escape。

## 探索选年与会话演进

- 游标目标年随指针与惯性更新，地图及会话仍保留上个生效年。停稳后和精确面板统一调用 `commitYear`，校验公元前 3500 年到当前自然年及无公元 0 年，再通过 `rememberExplore` 记录。返回时 `restoreExploreView` 根据已存的时间与图层偏好恢复有效分区。
- **Phase 05** 沿用 `globe.session.v1`、原有书卷、章节和地图身份，为正文位置加入可选字段 `blockId`。历史库的结构版本与会话存储版本分别维护。[历史内容模型](HISTORY-MODEL.md)
- **Phase 06** 观察记录另持有稳定 `phaseId` 和当前地点，退出恢复正文入口焦点。阅读导航帧可保存关系焦点，事件观察的可选 `eventList` 在重启后恢复发起观察的列表。场景、相机和关系日期继续隔离于原探索快照。
