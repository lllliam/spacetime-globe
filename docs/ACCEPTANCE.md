# Spacetime Globe 1.0 最终验收标准

本标准供 `1.0 · Final Acceptance` 使用。逐项记录待验构建的 commit、设备与浏览器版本、输入、预期、实测、复现材料和结论。记录失败或未执行的原因及责任阶段；产品负责人确认所有发布门槛后进入 [正式发布](VERSIONING.md)。

Phase 09 在候选报告和 16 项矩阵中记录工程结果、人工与真机范围、历史内容待办以及正式发布资格。工程检查通过后仍须分别完成后三类确认。[候选报告](progress/PHASE-09.md) · [验收矩阵](progress/phase-09/matrix.md) · [发布操作清单](RELEASE-CHECKLIST.md)

| # | 维度 | 通过条件 |
| --- | --- | --- |
| 1 | 首次使用与可发现性 | 清空专用测试配置后进入首页，显示编辑确认的历史年份，暂定 1500。首次使用者在无口头提示的任务中，能找到年份输入、时间轴、主体入口、目录、观察入口和返回操作。记录卡住的步骤 |
| 2 | 地球操作与时间定位 | 触控和桌面输入均可旋转、缩放和选取。拖时间轴与输入同一年得到同一标签、地球图层和选取结果。覆盖纪元边界、公元 0 年、超范围、取消和输入后焦点恢复 |
| 3 | 主体识别与书卷入口 | 在同一主体至少两个有覆盖的年份点选，得到同一稳定书卷 ID。摘要提示主体身份和相应年代，入口年提示章节且整卷可遍历。仅有地图的主体明确显示覆盖与来源 |
| 4 | 全屏阅读 | 手机和桌面打开正文时由纸面全屏承载，底部正文、注释和来源可完整滚动到。观察退出后回到正文，阅读期间没有无关地图自动抢占界面 |
| 5 | 目录与章节导航 | 从目录跳转、前后章切换、回到目录和沿关联返回均定位到正确章节，入口年提示与继续阅读可区分。读者能从任一入口进入其他章节 |
| 6 | 进度与重启恢复 | 对有至少两卷进度的测试配置分别执行刷新、关闭重启、探索与阅读互转。恢复最近有效的探索或阅读，书卷、章节、可识别的段落位置以及探索年份和镜头与预期相符。无效或旧记录有可用回退 |
| 7 | 独立历史现场 | 读者主动进入多阶段场景，切换阶段、地点、年份并旋转地球。离开后恢复原卷、原章、可见段落及返回焦点，再关书返回原探索年份和镜头。记录三个年份的独立值 |
| 8 | 全球历史关联 | 分别检查共时、比较和有证据的联系。类型、目标书卷/章节、年代与解释相符。实际联系能查到支持其成立的材料 |
| 9 | 史实、引用与审校 | 存量正文、专题和场景均有治理记录和明确审校状态。抽查引用可定位到支持相应论断的材料。《明朝》标杆逐章核对叙事、年份、引文、场景与地图来源 |
| 10 | 缺失与不确定性 | 用缺资料主体、争议年代及近似路线验证文案和地图图例。缺失有解释，近似与争议有可辨识线索。没有可用证据的路线及论断不会以确定事实出现 |
| 11 | iPhone、窄屏与桌面 | iPhone Safari 和主屏幕安装模式使用真机测试。覆盖 393×844 级视口、320px 窄屏、桌面宽屏及方向或可见视口变化。控件无截断、遮挡，最后一段可达，场景出入与返回位置可复现 |
| 12 | 无障碍、减动效与低性能 | 键盘能走通核心路径并能退出弹层，焦点可见且返回合理。屏幕阅读器可识别按钮、年份、标题及状态。减动效下无依赖动画的操作。记录低性能设备和 Canvas2D 降级下的交互、资源及性能结果 |
| 13 | 在线、离线与 PWA | 在线冷启动能取到所需资源。PWA 安装并完成规定缓存准备后，切断网络并重启应用验证核心路径。网络断开时本地双击单文件，验证探索、阅读和观察，区分内嵌正文与依赖公网的外部来源 |
| 14 | 构建与回归 | 干净检出执行内容校验和在线／离线构建。运行 UI、移动和 smoke 检查，验证 WebGL 与 Canvas2D。对常用路径记录错误、加载性能、重复操作、异步数据加载与跨重启恢复 |
| 15 | 一致性与克制 | 审核核心路径截图和操作录像，逐屏确认唯一主体与统一视觉语言。主要控件均服务历史理解，辅助信息按需出现，重复入口或会抢占主体的装饰获得处置 |
| 16 | 版本、缓存与发布 | 正式包、应用元数据、文档、产物和 `1.0.0` 发布记录指向同一验收 commit。分别验证冷启动与已有原型缓存升级，包括资源新旧组合、在线／断网恢复及持久化兼容。发布后按地址验证在线与离线下载 |

1.0 的内容交付是存量内容治理、可维护的编辑与审校体系，以及《明朝》标杆书卷。各卷的篇幅与章节由叙事和证据决定。性能场景与量化阈值随对应阶段的产品指令明确，最终记录实测数据及运行条件。
