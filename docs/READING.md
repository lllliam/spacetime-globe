# 阅读与内容组织

**现行工程与编辑说明。** 阅读目标由 [产品规范](PRODUCT-SPEC.md) 定义，当前会话与导航见 [状态模型](STATE-MODEL.md)，原始行为记录见 [工程基线](BASELINE.md)。

## 书卷与入口

`data/books/*.json` 以稳定 `id` 组织书卷。每卷标明起止年、摘要、来源和章节，仍存续可用 `to: null`。章节包含正文与段落 `refs`。年代标签可表达约略或传统分期，当前定位仍使用结构化年代。保留可追踪的 ID 和关系。通过[书卷范例指南](BOOK-EXEMPLAR-GUIDE.md)核对结构与编辑边界。

历史地图通过 `polities` 将底图实体匹配到主书卷。现代地图入口使用带年代的 `countries` ISO 绑定。底图覆盖、地图位置、书卷叙事范围各有口径。综合书卷可收录跨时代、跨地区或并行主体的历史。来源较少的主体先提供地图资料。编目数量见 [内容覆盖](CONTENT-COVERAGE.md)。

年表中 `data/world-reading.json` 按世界条目 ID 为书卷或书卷/章节建立入口，书卷章节的 `eventIds` 也可匹配带地图的专题事件。世界代表点常用于区域定位，精确事件地点须另有来源。现有 28 组专题、117 篇补充文章仍从历史书目访问。

阅读会话持有当前对象、入口年和导航链。章节切换、跨卷返回、观察回原文和浏览器重开共用逻辑阅读锚点。书卷和专题可各自保存进度。地图资料档案和历史书目仍使用现有界面入口，探索年份与地球选区在合书之后按有效身份恢复。

## 地图场景与关联

- `data/scenes.json` 独立记录稳定场景 ID、观察年、地点、角色和来源。可附时间阶段、路线、历史起止年。章节用 `sceneRefs` 引用，`after` 从 1 起算。同一场景可为多卷、多章复用。使用 `topicEvent` 可复用专题事件地图。
- `distanceBetween` 以标注坐标计算近似直线距离。历史行程、河道距离、旅行范围和路线需有相应证据。阶段可采用资料允许的近似年份。
- 区分延伸阅读、单纯共时、历史比较和有证据的实际联系。现有书卷 `contemporaries` 的目标和年份字段缺少完整的关联语义，Phase 06 确定治理办法。
- `data/polity-zh.json` 以底图原名映射中文标签，先使用常见译名，也可采用音译或描述性名称。部分关系使用已确认的两端名称生成，未能对应的名称在地图资料中保留原文。

[来源核查](SOURCE-AUDIT.md) 记录补充专题的既往审查。内容校验检查数据、来源索引和关系合法性。史实、解释与材料是否相符需要逐项查证。旧版操作指南见 [阅读档案](archive/design/READING-PROTOTYPE.md)。
