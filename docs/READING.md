# 历史书与地球

## 探索与阅读

首页用地球定位空间，用年份定位时间。长按年份原位展开，横拨停稳后更新疆域。点球面收起。单击年份从同期事件找书读，双击直接输入。长按地球打开底部面板，即时预览随年份、现代边界或地形，地名、经纬线和视角恢复在「显示选项」中。

在历史疆域中点击一个主体，半窗显示名称、全卷年代和简介，点击或上拉进入目录。点同一主体的不同年份会打开同一卷。目录突出入口年份所在章节，提供从头阅读、跳转和继续阅读。正文有连续的章节、段落来源及按需展开的地图和延伸阅读。

手动开启现代国家视图时，地图使用现代国界作为地理参照。只有编辑确认的现代国家和年代可以直接进入相应书卷。只掌握地图资料的主体显示资料范围和来源。重叠的历史轮廓留在阅读中的可展开说明，保留地球上实际选择的位置和年份。

## 返回与联动

- 半窗从抓手向上拖动展开，向下关闭。全文滚到顶后可直接下拉，松手返回进入前的半窗。正文未到顶时，下拉继续滚动。减少动态效果设置适用于松手动画。
- 全文从左边缘向右滑或按 Esc 返回上一层，目录层收回半窗。目录、章节和延伸阅读之间保留原滚动位置，书卷进度在当前页面会话内独立保存。
- 在正文中切换章节，地球保持进入时的年份、视角和选中主体。只有明确点击章节地图才切换到该地图所标的年份。从地图回到同一章、位置及地球镜头。
- 年份入口先展示具体事件，朝代和跨度较长的背景可按需查看。「读《书名》」进入对应章，收起后恢复原列表、位置和焦点。标题通往事件地图，可查看已知地点与参与方，只有地区资料时定位到相关区域。
- 首批章节地图覆盖靖难之役、1453 年君士坦丁堡、1842 年条约口岸及 1900 年义和团危机。点地名查看所在地在这段历史中的作用。

## 编辑与数据

`data/books/*.json` 中每卷有一个稳定的 `id`，内容从建立读到结束或当下。每章独立标明范围、正文和段落出处，现存主体将终年设为 `null`。章节中的 `map` 由编辑指定年份、地点、说明和出处。延伸阅读指向可验证的书卷、章节或补充专题。

疆域数据中的名称只用于构建时精确校验并生成地图实体绑定，阅读时匹配已编译实体和编目身份。国家入口也由编辑明确标明 ISO 和年份范围。地球上的几何覆盖范围来自 Cliopatria，历史书年代来自编辑选用的史料，两者各有口径。编辑为书卷选择内容，地图代表点用来定位世界表的区域资料。

`data/polity-zh.json` 维护底图原名与简体中文标签的精确对照。先采用常用中文名，再按需要使用音译或描述性译名。构建按已确认的两端主体名称生成同盟、共主邦联等关系标签。个别待考原名保留在地图资料的折叠项中。书卷的 `dateLabel` 可标注约略年代或采用的分期，入口定位仍以 `from` 和 `to` 为准。

既有 28 组专题及 117 篇文章保留在「历史书目」的「补充专题资料」。正文可按上下文链接到已编辑专题文章。详见 [内容覆盖](CONTENT-COVERAGE.md)。

`data/world-reading.json` 用条目 ID 维护年份入口的编辑关联。指定书卷时按入口年份选择章节，遇到跨越章节的具体事件可以显式填写书卷与章节。带专题事件地图的书卷关联仍由各章的 `eventIds` 维护。构建检查条目、书卷、章节和年代交集。

## 构建与验证

`src/subject-reader.js` 管理书卷归属和呈现，`src/reading.js` 管理导航、手势与阅读状态，`src/event-map.js` 管理世界表和章节地图的往返。运行 `node tools/verify-content.mjs` 检查章节、书卷归属、来源索引、地图和关联。运行 `node build.mjs` 同步在线与离线 HTML。浏览器回归 `node tools/verify-ui.js` 检查按年份命中、读书与地图相互返回及离线内容，`node tools/smoke.js` 检查常用触控入口。
