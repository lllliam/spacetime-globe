# 阅读与内容组织

**现行工程与编辑说明。** 阅读目标由 [产品规范](PRODUCT-SPEC.md) 定义，当前会话与导航见 [状态模型](STATE-MODEL.md)，原始行为记录见 [工程基线](BASELINE.md)。

## 书卷与入口

`data/books/*.json` 以稳定 `id` 组织书卷。每卷标明起止年、摘要、来源和章节，仍存续可用 `to: null`。目录按编辑指定的章节顺序展示，结构化年代和推荐优先级用于找章。正文块与来源各有稳定 ID，段落 `refs` 可加材料定位和注记。[历史内容模型](HISTORY-MODEL.md) · [书卷范例指南](BOOK-EXEMPLAR-GUIDE.md)

历史地图按底图实体、现代地图按 ISO，在 `data/history/map-bindings.json` 查找入页年代有效的主叙事与相关历史。没有主叙事时进入地图资料，并提供适用的相关历史链接。跨区域书卷可以附编辑范围说明。底图覆盖、地图位置与书卷叙事各有年代口径。编目数量见 [内容覆盖](CONTENT-COVERAGE.md)。

年表通过编译后的事件索引查找阅读入口。`data/world-reading.json` 可以明确指定书卷或章节，章节的 `eventIds` 也可声明关联。明确的章节优先于年份推荐，缺少合适章节时进入扉页并保留入口年。世界代表点常用于区域定位，精确事件地点须另有来源。现有 28 组专题、117 篇补充文章仍从历史书目访问。

阅读会话持有当前对象、入口年和导航链。首读进入整卷扉页，探索年只用于提示相关章节，目录可访问整卷。正文目录按钮保留原章和锚点，目录标明正在读、入口年、上次读到三种位置。从头读须经显式按钮，打开目录或临时查看另一章章首保留有效进度。书卷和专题分别保存进度。

历史书目、书卷首页、正文、补充专题及地图资料共用全屏纸面。地球摘要仍属于探索，地图资料明确标注正文收录情况及底图来源。合书按来源恢复摘要、史事列表或进入阅读前的事件观察。章内“阅读位置”是滚动比例。正文末尾可以主动进下一章，末章提供目录。

阅读字号有小、标准、大和特大四档，独立保存。换字号、旋转屏幕、调整窗口及重启后优先按正文块 ID 和块内偏移恢复。旧记录以文本指纹匹配并升级，已删除的块回退到同章滚动位置。编号引用通过稳定来源 ID 打开对应材料，合上注释回焦原编号。完整来源可在章末展开。

## 地图场景与关联

- `data/scenes.json` 独立记录稳定场景 ID、观察年、地点、角色和来源。可附时间阶段、路线、历史起止年。章节的 `sceneRefs` 用场景 ID 引用目标，并用 `afterBlockId` 锚定正文块。同一场景可为多卷、多章复用。使用 `topicEvent` 可复用专题事件地图。
- 场景以说明性图版出现在相关段落之后，显示原有标题、观察年及解释，读者可用按钮或已有地名链接进入独立观察。返回恢复原章锚点、场景入口及焦点。空间线索在章后按需展开。
- `distanceBetween` 以标注坐标计算近似直线距离。历史行程、河道距离、旅行范围和路线需有相应证据。阶段可采用资料允许的近似年份。
- 区分延伸阅读、单纯共时、历史比较和有证据的实际联系。现有书卷 `contemporaries` 的目标和年份字段缺少完整的关联语义，Phase 06 确定治理办法。
- `data/polity-zh.json` 以底图原名映射中文标签，先使用常见译名，也可采用音译或描述性名称。部分关系使用已确认的两端名称生成，未能对应的名称在地图资料中保留原文。

[来源核查](SOURCE-AUDIT.md) 记录补充专题的既往审查。内容校验检查数据、稳定引用和关系合法性。史实、解释与材料是否相符需要逐项查证。旧版操作指南见 [阅读档案](archive/design/READING-PROTOTYPE.md)。
