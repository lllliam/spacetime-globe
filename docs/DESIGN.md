# 设计实现说明

以下内容记录现有视觉语言与实现。1.0 产品决策以 [产品规范](PRODUCT-SPEC.md) 为准。未开始的实现由 [对应阶段](ROADMAP.md) 确定。

## 视觉与交互

- 深空地球与米纸书卷构成统一视觉语言。深墨蓝 `#0a1016` 为地球舞台，米纸色 `#f6f2e9` 为阅读底色。朱砂用于阅读主操作，靛蓝用于地点与来源。阅读样式集中于 `src/reading.css`。
- 以地球、正文或观察场景承载当前任务。时间、图层、目录、来源和说明按需出现。核心操作需要有可发现入口，并验证触控、键盘、焦点、减动效和窄屏可见区域。
- 场景图版与正文论点相邻。地点角色、阶段和路线的精度以来源能支持的程度为限。距离如按坐标估算，应说明其为直线距离。

## 首页与时间

- 首页常态保留左上年份、右上视图、地球、底部时间游标和「这一年」。首启以亚洲为主画面，1500 年疆域准备后显示。地名避开年份与时间区，短横屏调整地球中心和半径。
- 顶部年份点击或按 `F2` 打开精确面板，支持公元前格式、历史节点和回到当代。底部游标支持低速逐年、惯性滑动与键盘，拖动时并列标记预览年与地图生效年。空白点击可取消主体选择。
- 「这一年」可打开当年史事、长期背景或收录提示。视图设置集中管理随年份、现代边界、自然地形、地名、经纬线与复位。地球支持触控旋转、捏合、平移及桌面鼠标操作。
- 摘要集中展示名称、年代、短介绍及一个入口。书卷使用「阅读历史」或「继续阅读」，资料主体使用「查看地图资料」。[实际运行截图](progress/PHASE-03.md#实际运行截图)

## 全屏阅读

- 扉页居中呈现书卷、年代、简介和阅读入口，目录使用横线分隔的纵向行。正文左对齐，手机标准 18px、桌面标准 20px、行高 1.9，正文最大版心约 680px。系统优先选用宋体及其他中文衬线字体，正文和资料使用同一米纸色。
- 顶栏提供返回上一级、历史书目、章节目录、四档字号与按来源退出。正文自然纵向滚动并支持系统选取、复制和浏览器缩放。返回与注释面板保留正文位置和焦点。历史场景以轻边框图版呈现，经读者操作成独立观察。[视觉验收与实拍](progress/PHASE-04.md#实际运行截图)
- Phase 06 完善场景阶段、路线和全球关联。真机、安装和无障碍验收依据 [最终验收](ACCEPTANCE.md)。
