# 设计实现说明

以下内容记录现有视觉语言与实现。1.0 产品决策以 [产品规范](PRODUCT-SPEC.md) 为准。未开始的实现由 [对应阶段](ROADMAP.md) 确定。

## 视觉与交互

- 深空地球与米纸书卷构成统一视觉语言。原型外壳以深墨蓝 `#0a1016` 为地球舞台，米纸色 `#f6f2e9` 为阅读底色。朱砂用于主动作或关键引文，靛蓝用于地点与来源。原型样式和尺寸见 `src/app.css`、`src/chrome.css`。
- 以地球、正文或观察场景承载当前任务。时间、图层、目录、来源和说明按需出现。核心操作需要有可发现入口，并验证触控、键盘、焦点、减动效和窄屏可见区域。
- 场景图版与正文论点相邻。地点角色、阶段和路线的精度以来源能支持的程度为限。距离如按坐标估算，应说明其为直线距离。

## 首页与时间

- 首页常态保留左上年份、右上视图、地球、底部时间游标和「这一年」。首启以亚洲为主画面，1500 年疆域准备后显示。地名避开年份与时间区，短横屏调整地球中心和半径。
- 顶部年份点击或按 `F2` 打开精确面板，支持公元前格式、历史节点和回到当代。底部游标支持低速逐年、惯性滑动与键盘，拖动时并列标记预览年与地图生效年。空白点击可取消主体选择。
- 「这一年」可打开当年史事、长期背景或收录提示。视图设置集中管理随年份、现代边界、自然地形、地名、经纬线与复位。地球支持触控旋转、捏合、平移及桌面鼠标操作。
- 摘要集中展示名称、年代、短介绍及一个入口。书卷使用「阅读历史」或「继续阅读」，资料主体使用「查看地图资料」。展开纸面后沿用现有阅读布局。[实际运行截图](progress/PHASE-03.md#实际运行截图)

## 阅读与观察的阶段边界

| 主题 | 基线实现 | 1.0 决策／归属 |
| --- | --- | --- |
| 阅读 | 手机有摘要、半窗和全屏，桌面有左右同屏。Phase 02 新增可验证的本地会话与正文锚点 | 默认全屏正文和继续阅读界面改进。Phase 04 |
| 观察 | 正文图版可主动观察。桌面同屏地球还会按书卷、章节及滚动选取场景 | 主动进入独立场景，观察后返回原文。Phase 06 |
| 适配 | 现有布局考虑安全区、可见视口和减动效 | 用真实设备及自动化覆盖回归，按 [验收标准](ACCEPTANCE.md) 记录证据 |

v7 的常驻缩放和三态按钮、v8 的默认半窗及手势阈值属于[已取代的原型方案](archive/design/DESIGN-PROTOTYPE.md)。方案截图仅供[历史参考](archive/screenshots/README.md)。
