# 中国历史专项建设清单

现行优先范围由产品负责人指定。中国历史从原生分支 `92aae1b` 的内容续接。下表是建设顺序，书卷边界随材料和已有叙事安排。既有资源只作盘点，成熟度以实际证据和入口检验为准。

| 次序 | 阶段 | 已有资源与建设缺口 |
| --- | --- | --- |
| 1 | 史前文明与早期国家 | 《早期中国》现有十二章，新增江汉平原、辽西红山、鲁东南龙山、平潭与台湾的案例。其他龙山地区、长江中游南部、闽南与珠江流域仍待深化。 |
| 2 | 夏、商、西周 | 夏代文献与二里头已在卷际接通。《夏商与西周》现有十二章，包含早商城址、洹河都邑、甲骨、周初铭文、地方册命、江汉与共和纪年。其他地方社会和具体年代仍可随新材料深化。 |
| 3 | 春秋战国 | 下一阶段从两周之际到春秋早期。沿用《战国》及早期国家专题，补周王室、郑与晋等地方政治体及地图证据。 |
| 4 | 秦汉 | 沿用《秦》《汉》和河西相关现场。复核郡县实际管辖、交通通道、边地互动与王莽时段。 |
| 5 | 三国、两晋、南北朝 | 沿用《魏晋南北朝》。深化南北政权与人口迁徙，补同时代地图、年表和地方案例。 |
| 6 | 隋唐 | 沿用《隋》《唐》和长安现场。复核运河、边疆制度、海陆网络及与周边政权的联系。 |
| 7 | 五代十国、宋、辽、西夏、金 | 沿用相关书卷和汴京现场。整理宋卷一级待核论断，深化并存政权、区域经济和实际控制。 |
| 8 | 蒙古帝国与元朝 | 沿用两卷与相关场景。分开帝国、各汗国和元朝，优先处理现行台账中的重要数字、承继与地理关联。 |
| 9 | 明朝 | 继承 Phase 08 的标杆书卷及场景。只补现行年份总览、区域主体与观察入口中有据的缺口。 |
| 10 | 清朝 | 沿用《清》及相关场景。优先处置原风险队列，核对制度、地方关系及地图时段。 |
| 11 | 晚清转型、辛亥革命与中华民国 | 沿用晚清专题、《清》《中华民国》和相关现场。补不同地区的转型、港澳台及并存政治、社会经济背景。 |
| 12 | 1949 年以后 | 沿用现有书卷和东亚专题。明示资料截止时间，区分实际管辖、主张与史学解释。 |
| 13 | 跨时期专题及区域历史 | 复用专题和区域书卷，补边疆、多民族、港澳台、社会生活和与周边文明的真实联系。 |

每批按正文、主体与地图、年份背景和规范史事、现场、跨卷关系、证据六个方向追踪。一级风险沿 [稳定 ID 清单](historical-world/baseline.json) 在中国范围内逐项处置。其他地区此前有效的审校、记录和排队内容继续保留。

## 2026-11-26 · 史前与早期国家首批

- 新卷 `early-china-origins` 以贾湖、裴李岗和大地湾说明食物证据，以良渚、石峁和二里头展开不同地区的聚落演变，并承接原有 `shang-zhou/erlitou-shang-bronze`。修订该章 `p-01`、`p-02`，将传世王朝叙事和早商城市的考古分期分别引证。
- 良渚和石峁按考古年代显示为背景。良渚通过年度索引与正文进入 `liangzhu-waterworks`，可观察城址、谷口高坝、平原低坝与山前长堤、瑶山四处遗产区。点位代表遗产组成区，石峁本批提供区域背景与正文入口。现有地图最早到公元前 3500 年，卷首更早资料可从书目阅读。
- 良渚与两河乌尔按考古年代做同期对照。石峁章在种植叙事中引入有农作物遗存支持的欧亚传播，保留各地材料的测年及线路限制。[本批证据、处置与复核](historical-world/batches/02-china-early-origins.json)

## 2026-11-26 · 陶寺与中原龙山

- 在石峁与二里头之间补入陶寺和中原龙山两章，分别细读陶寺早、中、晚三期与营建变化，以及王城岗、古城寨和平粮台的城墙、壕沟、陶管和分期。新砦期承接至二里头，新砦的文献身份仍待独立证据。
- 「这一年的世界」新增两条考古年代背景。中原龙山从年度总览和书卷正文进入王城岗、平粮台的自然地形对照，遗址点用于区域定位。[本批论断、证据与复核](historical-world/batches/03-china-taosi-and-longshan.json)

## 2026-11-26 · 江汉、辽西、海岱与海峡

- 新增屈家岭、石家河、红山、海岱龙山、平潭和台湾六章。屈家岭用坝体剖面与食物残留说明江汉地区的水利和生计，石家河从较早的谭家岭城转到制陶、制玉和后段墓葬。红山区分居址和礼仪地点，海岱以日照的区域调查和石器加工遗物为主。平潭和台湾分别从陶器比较和作物测年切入，并把台湾与北吕宋的关系放回两地材料。
- 六条年代背景以区间呈现。四个场景对照江汉平原、红山遗址、鲁东南两处龙山中心和台湾海峡两侧的地形。遗址区用参照点定位，具体遗构、古岸线、路线和各期范围以原始材料为准。[本批论断、证据与复核](historical-world/batches/04-china-prehistoric-regions.json)

## 2026-11-26 · 早商城址至殷墟

- 《夏商与西周》新增偃师与郑州、盘龙城、洹北至殷墟和武丁时期甲骨读法四章。修订早商与晚商原章中的铜料、迁都、武丁、妇好与车马论断，并用利簋补足克商段的证据。郑州所检矿料的九瑞来源和盘龙城本地熔铸各有证据，具体运输路径待查。
- 五条年代背景采用考古或测年区间。三个观察现场分别定位偃师与郑州、作坊与九瑞矿集区、洹河两岸的城址和王陵。洹北郭城的描述纳入沟槽解剖所得的城壕证据。武丁区间采用一套模型，书内注明其他纪年方案。[本批论断、证据与复核](historical-world/batches/05-china-shang-cities-and-oracles.json)

## 2026-11-26 · 西周铭文、地方与共和纪年

- 新增周初东方战事与成周、燕与宜的地方册命、昭王南征与叶家山、共和纪年四章，重写周初和西周中后期的原有两章。区分何尊出土地与成周、伐荆器铭与南征过程、年表换算与执政者记载，并以《系年》对读西周末的王位争立。
- 加入三条考古年代背景，以及采用通行换算的前 841 年共和元年、前 771 年幽王身亡两条史事。三个现场以出土区和遗址区定位。原丰镐与成周现场保留稳定入口，更新参照位置和补充证据。[本批论断、证据与复核](historical-world/batches/06-china-western-zhou.json)
