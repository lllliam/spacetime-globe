# Phase 08 · 标杆书卷《明朝》

《明朝》已按 Phase 08 指令建设，交产品负责人验收。开发基线为 `53232095f5534b50ab65d0a7d18af0a7038b6714`，审校差异的内容基线为 `2d8233b`。开发分支交付历史数据、来源与场景、兼容修复和回归、在线构建与单文件离线构建。正式发布仍包含完整历史内容验收。

开国两章把应天政权与河工、地方武装和新编簿册接起来。之后追踪粮食、劳役、赋税和信息怎样跨区域转运，由此进入京畿边防、地方家计、白银市场和战时征发。成化、弘治至正德有独立章，宫廷任用与实际文书手续同时进入叙事。尾声分别追踪南京、福建、两广、西南及台湾的政治转换。

《把税粮送到通州》从入仓前的经手人写起，旁引放在相应正文段落。史料将民运与军运分开，也留下监收、耗米与补军役的记录。

> 把一袋谷子从收成账写进北京仓的入库账，中间至少会遇到两种人。一种是履行纳粮义务的民户和他们所雇的人，另一种是负责转运的军户。

## 来源与复核

五批正文先查所涉材料再行写作。保留原书 42 个来源身份，复用相关材料并按需补充，现有 98 个书卷来源身份。查读的具体章节、公开摘要和受限记录均在批次中标明，引用只承接所能读到的范围。同一编辑在定稿后复读全卷，回查关键事实、引用、因果解释、重复、章间接续及场景和关系。第二遍复核记录在 127 个对象上，由同一 AI 完成。

| 材料组 | 本轮查读及采用的范围 |
| --- | --- |
| 王朝与制度 | 《元史》顺帝本纪、《明史》太祖、建文、成祖至庄烈帝相关本纪，以及食货、职官、漕运、陈瑄、周忱等条。用于制度设置、具体年份和因官书视角保留的限制。 |
| 地方与实物 | 淮安地方材料与陈瑄传互证清江浦。故宫的成化瓷器与窑址报告、明代家庭劳动研究、宝钞展签和《十竹斋书画谱》印本补充官书的视角。 |
| 海路与白银 | 《明史》郑和传、航海博物馆的航次、海外贸易和白银研究、大都会马尼拉航运资料。日本银、马尼拉交易、地方折银与明廷饷银各自取证。 |
| 战争与易代 | 韩国学中央研究院的壬辰战争及《宣庙中兴志》目录说明、《明史》《清史稿》、易代研究和台湾史资料。用于半岛作战、北京与南京的政权转换、南明与郑氏活动的时序。 |

同一笔银由哪处矿山经何港进入某县，现有材料很难追踪，贸易占比的估计也有分歧。迁都与停航各有多种解释，行动者的私人动机仍有材料限制。官书可记录气候、钱粮或军政决定，地方执行及影响须按时地另查。研究中遇到访问受限、摘要范围和单一记录无法证明的内容，具体处置见批次。[五部来源与论断批次](phase-08/batches/) · [审校前后对照](phase-08/changes.json)
