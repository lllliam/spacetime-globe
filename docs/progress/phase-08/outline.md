# 《明朝》目录与身份规划

全卷主体年代为 1368—1644 年。前史和尾声采用独立章型，地图主入口维持原政权范围。目录按下列叙事顺序组织。重点追踪地方资源如何经官员、军户、漕运和市场进入国家，同时说明账册、港口和地方社会留下了不同种类的证据。

| 部 | 章序与稳定 ID | 本部研究问题 |
| --- | --- | --- |
| 一个王朝的诞生 | 元末危机 `yuan-crisis` → 开国 `founding` → 户籍与卫所 `households-garrisons` → 洪武中枢 `hongwu-court` | 从河工、元末政治、诸军立足点和赋役账册，解释新政权怎样组织人力、土地和粮食。 |
| 帝国的扩张与重心转移 | 靖难与两京 `two-capitals` → 漕运劳动 `canal-labor` → 郑和与印度洋 `indian-ocean` → 仁宣调整 `renxuan` | 对读本纪、运输记录与下西洋材料，追问定都后的供给、人员和对外往来的代价。 |
| 繁荣背后的矛盾 | 土木之变至嘉靖 `mid-ming` → 宫廷文书与政治 `court-paperwork` → 家计与地方资源 `local-livelihoods` → 东南沿海与北边 `coastal-frontier` | 用宫廷文书、军籍、商品和地方材料解释政策为何随人员、地区和时间变化。 |
| 进入全球贸易时代 | 张居正与征收 `zhang-reform` → 港口与白银 `silver` → 印刷与知识 `print-and-knowledge` → 万历与东亚战争 `wanli-imjin` | 区分官府收入、市场交易和商路规模，观察印刷、译书和战争各自牵动的人群。 |
| 大明的最后岁月 | 辽东与天启 `liaodong-tianqi` → 灾荒、加派与民变 `famine-rebellion` → 1644 年 `fall` → 南明与易代 `southern-ming` | 分辨生态、财计、边战和军政选择的作用，以及北京失守之后的不同政治时序。 |

`ming` 及五个原章 ID 沿用。原段落及旁栏留在原章并承接原论点，深化章节使用新 ID。旧场景图版及地名链接保留原锚点，其解释和证据以实际查证结果更新。旧来源 ID 的原题名和 URL 保留。已审对象与暂存台账的精确版本差异另外登记。

1400 年推荐靖难主线，1500 年优先推荐成化、弘治及正德前后的中期政治章，1600 年优先推荐万历时期政治与战争章。具体优先级以结构化推荐范围及运行验证为准。`i-040` 王朝长条保留整卷入口并按实际入页年推荐。`i-013` 跨越洪武到隆庆，单独核对东南沿海章是否能说明政策的起点和转折。
