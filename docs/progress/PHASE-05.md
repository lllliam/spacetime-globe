## 历史内容模型与阅读路径

- 历史内容模型 v1 为地理区域、历史政权、文明社会、现代国家和书卷定义不同身份。编辑主体按需登记。Cliopatria 原名与 Natural Earth ISO 引用现有底图数据，地图引擎继续使用包内索引。书卷 ID 独立，可涉及多个主体，也可没有地图绑定。
- 地图入口注册表按对象、适用年代、书卷目标、关联方式和范围组织。任一对象在同一年最多有一个主叙事入口，可同时有多条相关历史。冲突主入口拒绝构建。已有明朝路径在 1400、1500、1600 年均打开同一 `ming` 书卷。没有主叙事时继续提供地图资料。
- 书卷可有一章或多章，目录与连续翻章按编辑顺序。允许年代重叠、空档、专题、回顾及书卷范围外有说明的尾声。补充专题的固定篇数、字数、小节数与来源数量限制改为结构和编辑检查。检查无效年代、重复正文、引用、位置及其他关键关系。
- 扉页与事件共用章节推荐。准确覆盖的普通叙事章默认参与，其他类型可显式参与，优先级处理重叠，同级可并列，空档留在目录。世界年表的明确章目标优先。48 个事件阅读入口并入同一索引，其中 46 个来自 `world-reading.json`，2 个来自章节 `eventIds`。事件入口年保留原值。
- 书卷正文、补充说明、空间线索、专题开篇及节正文使用存入源文件的稳定块 ID。来源 ID 在对应书卷、专题篇章或场景范围内稳定，可附页码等定位及说明。界面继续显示连续编号。新建和重排来源时，引用保留原材料目标。
- 48 个独立场景、49 个章内引用和原有地点、阶段、路线均保留。图版通过 `afterBlockId` 跟随正文块。跨卷、同期、专题连接与年表延伸阅读保留原有目标，可增加关系类型和证据。关系语义治理归 Phase 06。
- `globe.session.v1` 沿用 schema 1。恢复优先使用书卷或专题、章、`blockId` 和块内偏移。旧记录用文本指纹定位，命中后逐步写回稳定 ID。锚点块删除时回退到同章保存的滚动位置。探索镜头、时间、来源与观察返回沿用原语义。

维护规范及合法和非法示例见 [历史内容模型](../HISTORY-MODEL.md)。

| 巴基斯坦 `PK` | 《印度》主叙事 | 地图资料内提供相关历史，指向分治及克什米尔背景所在章 |

| 斯里兰卡 `LK` | 《印度》主叙事 | 地图资料内提供相关历史，指向阿育王时期佛教传播所在章 |

| 格陵兰 `GL` | 《北美原住民、新法兰西与现代加拿大》主叙事 | 地图资料内提供相关历史，指向加拿大北极与格陵兰的因纽特文化和地缘背景所在章 |
