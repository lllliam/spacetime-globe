## 产品路径

从干净的 Edge 配置打开真实 `index.html`。用浏览器鼠标、滚轮和键盘输入，在 1500 年点选明朝疆域，打开推荐、从头阅读和长篇目录，查看脚注。由两都章进入大运河，按阶段切年、选择清江浦、旋转缩放并核对资料，然后恢复正文位置和焦点。通过墨西哥谷地关联前往阿兹特克书卷再返回。合书恢复明朝摘要与 1500 年探索。

在前 221 年，底图仍有秦国与春秋战国实体。按该底图打开春秋与战国，再由现有书目进入《秦朝》第一章，探索年维持前 221 年。1500 年北亚的蒙古汗国可打开地图资料。1842 年史事可进入条约观察，在 1900 年可进入晚清专题。检查浏览器导航返回和真实重启后继续《明朝》。

精确输入、公元 0 年、纪元与年代边界、地图拖动与缩放、拾取、现代参考和自然底图沿用首页及 UI 回归。额外阻断实际世界数据请求，验证启动重试。慢网在真实疆域请求挂起时连续提交 1400 和 1600 年，进入并退出阅读，再释放请求，验证按最新年份绘制。WebGL 上下文丢失时保留原相机与年份，使用 Canvas2D，恢复时重建纹理与渲染状态。

## PWA 与离线

| 项目 | 候选处理 |
| --- | --- |
| 核心依赖 | 在线 HTML、清单与触发的图标、`world.json`、压缩和原始疆域、基础浮雕。书卷、年表编目与基础地表及云层随 HTML 内嵌。 |
| 可选依赖 | 高清地表和 4K 地形按需获取，失败时仍可用基础底图。 |
| 清单与完整性 | 构建从引用和运行时依赖生成清单与 SHA-256。在全部核心资源落盘后记录准备完成。 |
| 更新 | 路径与内容标识隔离缓存。活动版本提供自己的 HTML。新版本完成准备后在等待状态，旧客户端释放后激活。 |
| 恢复 | 视图设置可查看状态和重试。请求失败、响应完整性不符或配额不足会保留最后完整版本。 |
| 迁移与清理 | 只回收同一项目路径已激活的旧版候选缓存。原型 `globe-v24-icons`、其他项目缓存、存储键与安装作用域保留。 |

使用 Edge 的 loopback 安全上下文，在项目子路径执行真实 Service Worker、旧原型迁移、HTTP 503、请求中断、过期地图字节、配额覆盖、关闭浏览器中断新版安装、多标签等待、缓存驱逐及重试。两个构建的公开数据版本由独立的本地测试副本提供。用同一浏览器配置断网重启，验证候选核心地图、原显示偏好及书卷观察。实验的同源其他项目数据均为专用测试缓存。[PWA 日志](phase-09/pwa.json)

单文件在真实 `file://` 运行。Edge 断网逐章验证 57 卷 243 章、逐篇验证 28 组 117 篇，检查来源标题、图版入口及跨卷。对没有 `DecompressionStream` 的环境使用内嵌原始疆域，体积相应增加。提供外部来源的可访问说明和链接，打开外部站点需要网络。文件会话恢复按浏览器对该地址的本地存储策略执行。

## 性能与显示范围

环境为 Windows 10 专业版 19045，AMD Ryzen 5 7600X、31.1 GiB 内存，主机报告 AMD Radeon Graphics 与虚拟显示适配器。使用 Edge 158.0.4370.33、无头窗口和软件图形路径，本地 HTTP，1366×768 DPR 1，开启减动效。冷和缓存启动各五次，HTTP 缓存重入与 Service Worker 断网重启分别验证。无网络或 CPU 节流的基线对照和指定慢网场景分别记录。

详见 [启动实测](phase-09/performance.md) 及 [稳定性样本](phase-09/resilience.json)。使用开发者协议读取可访问树并核对按钮、年份和时间轴，测试键盘导航、焦点、注释弹层、缩放及减动效。覆盖 320×568、393×844、430×932、844×390、1366×768、1920×1080。触控和系统安全区为 Edge 模拟。硬件 GPU、其他浏览器引擎、VoiceOver 等原生辅助技术和 iPhone 需另行验证。[受控真机与人工清单](phase-09/device-checklist.md)

1. **产品及工程验收状态。** 已完成本环境的工程验收，可以把候选交给产品负责人使用。遗留软件渲染表现与检查限制见性能报告。
