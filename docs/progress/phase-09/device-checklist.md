# Phase 09 真机和人工验收

## 受控 iPhone 预览

将候选提交的完整构建放在已有授权的 HTTPS 静态预览站点，路径可取 `/spacetime-globe-rc/`。保留相对路径、`sw.js`、清单、图标及 `data/`。证书须被 iPhone 信任。预览与稳定 Pages 使用不同的来源。维护人员记录预览地址、候选提交和资源哈希。内网预览可使用 iPhone 可达的可信 HTTPS 代理。

记录设备型号、iOS 版本、Safari 与主屏幕启动方式、时间、候选提交和截图。用专用测试来源完成以下任务。

- Safari 首启，确认 1500 年地图、年份输入、时间轴和主体摘要。伸缩地址栏，检查刘海、底部安全区、触控旋转缩放和横竖屏。
- 从分享菜单添加到主屏幕，独立窗口重开。打开《明朝》推荐章和目录，改字号、看脚注，打开大运河图版并返回原段。
- 从视图设置确认离线核心资料已准备。开飞行模式，完全退出预览应用后重开。核对地球、历史疆域、书卷、图版及旧位置。
- 请预览维护人员在同一路径换一套后续测试构建。保持旧窗口查看新版等待提示。关闭所有预览窗口再打开，检查更新和原阅读位置。用故意缺核心资源的一套测试构建复验旧版可继续打开。
- 切到其他应用再回来。用 VoiceOver 读取年份、错误提示、目录、来源和观察返回，再从「这一年」进入书目。记录实际朗读和焦点顺序。

## 产品负责人体验

从干净浏览器配置按目标寻找精确年份、明朝书卷、目录、脚注、观察和返回。自行定位公元前 221 年，选择同时存在多个政权的区域，再查看一处只有地图的主体。记录需要提示的环节、误解的文案和无法完成的操作，附当前屏幕或短录像。
