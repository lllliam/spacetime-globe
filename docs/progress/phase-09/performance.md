# 性能基线与候选实测

源版本为 `1575242` 和候选实现 `2a51d25`。Windows 10 19045，AMD Ryzen 5 7600X，31.1 GiB，Edge 158.0.4370.33。运行 1366×768、DPR 1、减动效和无硬件 GPU 的无头窗口，显卡路径为 Microsoft Basic Render Driver 的 D3D11 软件图形。测试走同机 HTTP，关闭 Service Worker 干预，资源 HTTP 缓存有效期为 300 秒，无网络或 CPU 节流。冷启动每次用新配置。缓存启动是同进程离开再打开应用，五次响应的 HTML 和已用数据均无网络传输。离线 PWA 的真实重启在独立缓存专项验证。

每套版本冷启动、缓存重入各五次。以下为毫秒，中位数／最慢样本，四舍五入。阅读计时覆盖点击并同步呈现内容，观察往返脚本含场景启用和返回正文。

候选冷启动中位数比基线慢约 0.15 秒。缓存重入的可操作时间差约 0.01 秒，首次历史疆域慢约 0.20 秒。该软件图形环境的冷和缓存重入均高于参考目标，缓存重入的网络传输量为零。低延迟材料获取后仍需初始化页面、地球与疆域，硬件浏览器的启动表现留待实机确认。开卷、翻章与观察往返均在约 200 毫秒以内。

同机单独执行渲染稳定性时，软件 WebGL 帧率样本约 35.3、37.4 和 39.2 FPS，Canvas2D 约 30.5、32.2 和 31.7 FPS。独立的无硬件 GPU 环境用于验证核心操作及降级。桌面硬件 60 Hz 目标尚待实测。50 次观察往返约 2.8 秒。收集后的 DOM 文档、节点和 JS 监听器在预热、25、50 次后三次均为 1、918、101。无持续 DOM 增长证据。全屏读书无空转地球帧，冻结和恢复后仍在同章。模拟 150 毫秒延迟、2 MiB/s 时，实际旧疆域请求完成后呈现最新的 1600 年。
