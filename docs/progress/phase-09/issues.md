# Phase 09 问题及复验记录

| 等级 | 实际发现 | 处理及复验 |
| --- | --- | --- |
| P0 | 原型允许不完整预缓存激活，初装缓存无历史疆域。旧激活还会清理同源其他应用缓存。 | 用稳定原型实测复现。生成带完整性校验的核心清单，按路径及版本缓存，等待旧客户端释放。候选复验真实升级、故障注入、保留同源缓存及断网重启。 |
| P0 | 旧工作流允许从选定分支手动运行，写权限可把生成物推向主分支。 | 工作流只读，主分支门控，生成物做差异核对。 |
| P0 | 世界数据获取失败会停在启动遮罩。 | 加入可聚焦的加载重试，在浏览器阻断世界数据请求后复验。 |
| P1 | 在线压缩疆域 HTTP 失败会跳过原始备用文件。早期浏览器打开旧单文件时缺少解压接口就无法读取疆域。 | 在线支持未压缩备用，单文件内嵌原始疆域。复验缺少 `DecompressionStream` 时的在线与断网路径。 |
| P1 | WebGL 上下文丢失后缺少渲染恢复及状态提示。 | 保留同一交互表面，临时切换 Canvas2D，再重建 WebGL 资源。以浏览器真实上下文丢失与恢复复验。 |
| P2 | 原型 API 脚本会逐文件写入默认分支，上传范围早于现有建置。 | 移入原型档案，现行发布使用版本清单。 |
| P2 | 部分软件渲染环境的性能与高刷新目标有差距。 | 记录相同条件下的启动对照和软件 WebGL／Canvas2D 实测。 |
| 内容 | Phase 06 的四个暂停场景及旧路线，Phase 07 的待审论断、入口、来源与底图元数据。 | 继续按原审校范围保留，待审范围及 469 条地图入口列入完整内容验收。 |
| 环境 | 前期报告遗留 iPhone 安装、安全区、断网更新和原生读屏。 | 浏览器结果单独记录，并提供 [真机和人工验收](device-checklist.md)。 |
